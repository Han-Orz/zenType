# zenType 2.9.0

思源笔记的顺滑光标、打字机滚动与涟漪聚焦。这是 v2.9 的首版重构实现，等待真实思源中的体验验证。

## 写作体验

- 光标短距离平滑移动，停笔后轻微呼吸；大跳转直接定位。
- 输入停顿 400ms 后，在越过舒适区时调整滚动；靠近可视边界立即保护可见性。
- 当前块保持清晰，周围块与列表旁支渐淡；当前块内按句子聚焦。
- 鼠标操作、手动滚动、纵向导航、失焦与切换编辑器退出聚焦和自动跟随。
- 中文 IME 组合期间使用原生光标并暂停自动滚动；提交后恢复。
- 无可靠几何、非折叠选区、只读区、标题、数据库、嵌入编辑器和悬浮编辑区使用宿主行为。
- 尊重系统“减少动态效果”。

顶栏按钮或 Ctrl+Alt+Z 联合切换打字机与涟漪；命令面板支持单独切换。功能开关默认打开，在正文输入后进入写作会话。

## 本地体验

已有依赖时：

```sh
npm run typecheck
npm run build:dev
npm run build
```

开发构建在 `dev/`，生产构建在 `dist/`，可安装包是 `package.zip`。将包内文件放入思源工作空间的 `data/plugins/zenType/`，然后重新加载插件。

已有开发链接时，重建 `dev/` 后重新加载插件。尚未创建开发链接时可运行 `node scripts/make_dev_link.js --workspace <思源工作空间路径>`，脚本拒绝覆盖已有插件目录。`npm run dev` 持续构建开发包。此版本没有 DebugKit 或调试桥接服务。

重点体验中文输入法、快速方向键、连续 Enter/Backspace、列表 Tab/Shift+Tab、滚轮接管、分屏切换和插件停用后的原生光标恢复。

## 实现边界

一个输入入口、一个帧调度器、Cursor / Typewriter / Ripple 三个直接效果。先读几何，再写视觉。

没有结构 FLIP、结构稳定事务、跨 DOM 替换的动画交接或句子动画身份。文本或结构改变时直接采用当前状态；稳定文本中的句子切换最多保留一组进入/退出过渡。

历史测试原样保留，此轮未运行，也未适配新架构。当前验证方式是类型检查、构建与真实思源体验。

实现说明见 [设计文档](docs/DESIGN.md)。动效参数集中在 `src/config.ts`。
